# Student Attendance Management System

## Project files
- `index.html` — website structure
- `style.css` — website design and layout
- `script.js` — date display, Present/Absent buttons, and attendance totals

## Open in VS Code
1. Extract the ZIP file.
2. Open VS Code.
3. Select **File → Open Folder**.
4. Select the extracted `StudentAttendance` folder.
5. Open `index.html` and run it using Live Server, or open it directly in a browser.

Keep all three files (`index.html`, `style.css`, and `script.js`) in the same folder.

## Deploy using GitHub Pages
1. Upload all three files to a public GitHub repository named `StudentAttendance`.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then click **Save**.

Note: This is a frontend demonstration. Attendance changes are not saved permanently and there is no login or database.
